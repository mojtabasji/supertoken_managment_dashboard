# UI Design Skill

When building or modifying UI:

## Design
- Establish a clear visual hierarchy.
- Use consistent spacing, typography, colors, and component patterns.
- Prefer clean, modern interfaces over generic default styling.
- Design mobile-first and make layouts responsive.
- Avoid unnecessary visual complexity.

## Components
- Reuse existing components before creating duplicates.
- Keep components composable and focused.
- Use semantic HTML where appropriate.
- Provide meaningful loading, empty, error, and success states.

## Accessibility
- Use accessible labels and semantic elements.
- Maintain sufficient color contrast.
- Ensure keyboard navigation works.
- Do not rely on color alone to communicate state.

## UX
- Make primary actions obvious.
- Minimize unnecessary clicks.
- Give users immediate feedback after actions.
- Handle edge cases explicitly.

## Implementation
- Inspect the existing project and design system before changing UI.
- Follow the project's existing framework and conventions.
- Do not introduce a new UI library unless necessary.
- Test responsive behavior after significant UI changes.
